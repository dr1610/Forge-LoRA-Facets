# Forge LoRA Facets

Forge NeoのLoRAタブ上部に、Civitai情報を利用するジャンル・タグの絞り込みを追加します。Forge本体・LoRAファイル・既存のCivitai JSONは変更しません。

## インストール

Forge Neoの **Extensions → Install from URL** に本リポジトリのURLを入力し、インストール後にForge Neoを再起動してください。ZIPを使う場合は、展開したフォルダを `extensions/forge-lora-facets` に配置します。

追加のPythonパッケージのインストールは不要です。Forge Neoに含まれるFastAPI・Pydantic・requestsを利用します。

## 検索の違い

- **Forge標準の検索欄**：ファイル名などの文字検索です。標準のAND・部分一致・順不同の動作を維持します。
- **本拡張の「タグを探す」欄**：選択できるタグの候補を絞り込みます。ファイル名の検索欄ではありません。
- **選択したタグとジャンル**：標準検索の結果をさらに絞り込みます。ファイル名とタグをまとめてOR検索する機能はありません。

たとえばファイル名が `blue_uniform_v2`、タグが `clothing` のLoRAは、標準検索欄の `blue` とジャンル「衣装」を組み合わせて探せます。

## 使い方

1. このフォルダをForge Neoの `extensions/forge-lora-facets` に置き、Forge Neoを再起動します。
2. txt2imgまたはimg2imgのLoRAタブを開きます。
3. ジャンルボタンを選びます。複数選択はORです。「すべて」でジャンル条件を解除します。
4. 「タグで絞り込む」を開き、タグを複数選択します。「すべて含む（AND）」「どれか含む（OR）」を切り替えられます。
5. 通常の検索欄・フォルダ選択・モデル種別フィルターの結果と、ジャンル・タグ条件をANDで組み合わせます。

タグの絞り込みはタグ全体の一致です。大文字・小文字、アンダースコアとスペースの違いは吸収します。タグ候補を探す入力欄は部分一致です。Forgeの通常検索欄の仕様は変更しません。

## 分類情報

- LoRAと同名の `.civitai.json`（civbrowser）、`.civitai.info`（Civitai Helper）、`.info.json` を読み込みます。
- Civitaiのタグ・category/categoriesと既定のジャンル対応表を照合します。タイトルからの推測はしません。対応情報がなければ「未分類」です。Civitaiの画面上の全カテゴリと完全に同一になる保証はありません。
- 「不足情報をCivitaiから取得」はタグがないLoRAを対象にします。モデルID、またはファイル全体のSHA256ハッシュで照合し、モデル情報からタグを取得します。送るのはID／ハッシュで、モデル本体は送信しません。
- API認証なしで取得できる公開情報を利用します。削除・非公開・認証要求・通信制限などは取得失敗として表示します。各カードの「分類編集」に詳細を表示します。
- 取得はバックグラウンドで逐次実行します。「取得停止」で停止できます。通信中の場合はそのリクエストの終了／タイムアウトを待ちます。
- 情報が古いときは、カードの「分類編集」からそのLoRAだけ再取得できます。
- モデル追加時はForge標準の一覧更新を実行し、その後「分類情報を再読込」を押してください。

## 手動修正

各カードの「分類編集」でジャンルとタグを修正できます。手動修正は自動情報と別に保存し、再取得後も保持します。「自動分類に戻す」で修正を解除します。

保存先は拡張内の `data/catalog.json`。バックアップ時にはこのファイルを含めてください。分類情報はファイルの絶対パスに紐づくため、LoRAを移動・改名した場合の手動修正の自動移行は行いません。

保存済みCivitai情報の索引は `data/catalog-index.json` にキャッシュします。初回は情報ファイルを読むため、大規模なライブラリでは数分かかる場合があります。次回からは変更された情報ファイルだけ読み直します。

ジャンル／タグの選択状態はブラウザのタブ内で保持します。タグ候補は頻度順の上位120件を表示し、候補検索で全タグから探せます。ジャンルボタンの数字は登録全体の件数、上部の「件表示」は現在のカード一覧での件数です。

## 解除

ForgeのExtensions画面で本拡張を無効にして再起動します。LoRAや既存メタデータの復元操作は不要です。

## 検証

`python -m unittest discover -s tests -v`

対象環境: Forge Neo、ローカル確認リビジョン `6f616e8d`。ホストのExtra Networks DOM (`*_lora_pane`, `*_lora_cards`, `data-name`) と `on_app_started` / `onUiLoaded` / `onUiUpdate` を利用します。
